# Amaal AI

Amaal AI is Amaal's governed intelligence and orchestration layer.

It operates only through permission-aware Amaal tools and application services. It does not receive unrestricted SQL, direct database authority, provider secrets in browser code, or a self-approval capability.

Stage 8 provides:

- deterministic intent routing
- permission-filtered OpenAI function tools
- scoped ERP/reporting/knowledge reads
- bounded conversation continuity
- auditable tool invocations
- human-reviewable high-risk action plans
- normal Amaal approval integration
- a narrow approved recovery execution bridge
- governance/tool-policy version pinning and 24-hour action-plan expiry
- deterministic output guardrails for protected implementation material
- model-independent Stage 8 Evaluation Center and red-team regression tests
- audit events for rejected tool attempts and blocked model output

Amaal AI can be disabled without disabling the ERP. Neon remains the authoritative source of business truth.


Stage 9 adds read-only predictive tools backed by durable ML prediction read models. Jarvis may explain predictions, but predictions never become authorization and never directly mutate ERP state.

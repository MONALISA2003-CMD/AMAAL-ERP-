# Amaal dependency locking policy

Production and CI builds use Node 24.x and npm.

The release repository now declares npm workspaces at the root and pins internal `@amaal/*` dependencies to the exact local package version `0.0.0`. Vercel installs only the standalone `apps/web` package. Render installs the full monorepo with `npm install --no-audit --no-fund --package-lock=false`.

A real `package-lock.json` should be generated by `.github/workflows/generate-lockfiles.yml` on a network-capable GitHub runner and committed before the final Stage 10 reproducibility gate is enabled. A lockfile must never be fabricated by hand.

The Python intelligence service uses Python 3.13 for the current deployment image, exact top-level versions recorded in `services/intelligence/requirements.lock`, and a committed `uv.lock` once network-capable dependency resolution is available.

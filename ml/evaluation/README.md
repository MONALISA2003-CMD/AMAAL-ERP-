# Amaal ML evaluation

Stage 9 evaluates more than a single accuracy number.

Required dimensions:

- temporal holdout performance
- calibration for probability models
- stability across regions / teams where sample size permits
- missing-data robustness
- drift / freshness
- false-positive and false-negative operational cost
- reproducibility from dataset + feature schema + code version
- shadow-vs-baseline comparison

A prediction is never treated as ERP fact. The Recovery, Inventory, Sales and Finance services remain authoritative.
